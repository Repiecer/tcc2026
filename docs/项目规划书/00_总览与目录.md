## 一、项目一句话简介

利用 **1981—2025 年暖季（重点 5—8 月）ERA5 再分析资料**，构建长江中下游区域
**标准化高温指数 H**，提取**提前 1、2、3、4 周的大气—陆面前兆信息**，
用**从基线到机器学习（Linear → Random Forest → XGBoost）**的模型体系做连续预测，
再通过**极端阈值二阶段识别**给出极端高温预警，最后用 **SHAP + 物理机制诊断**
回答"模型学到了什么、是否合理"。

## 二、关键信息速览

| 项目 | 内容 |
| --- | --- |
| 研究区域 | 长江中下游地区（建议约 28°–34°N，110°–122°E，最终以方案定稿为准） |
| 研究时段 | 1981—2025 年暖季，现阶段重点 5—8 月 |
| 数据来源 | ERA5 再分析（单层要素，必要时加入气压层要素 Z500、850 hPa 风场；SST） |
| 预测对象 Y | 标准化高温指数 `H(t) = [Tmax_region(t) − Tclim(d)] / σ(d)`，后续扩展"高温增强幅度 ΔH" |
| 预测因子 X | 前期 T2m、D2m、MSLP、TP、SSRD、SWVL1、AVG_SLHTF，扩展 Z500、850 hPa 风场、SST |
| 提前期 | 1、2、3、4 周（lead week 1–4） |
| 模型体系 | 气候态基线 → 持续性基线 → Linear/Ridge → Random Forest → XGBoost |
| 数据集划分 | 训练 1981—2015；验证 2016—2020；独立测试 2021—2025；辅以滚动验证 |
| 连续评价 | MAE、RMSE、相关系数 R、R²、相对基线的技巧评分 |
| 极端事件评价 | 90%/95% 分位阈值下的 Precision、Recall、F1、ROC-AUC、HSS、TSS |
| 可解释性 | SHAP + Permutation Importance + 分组消融实验（三重交叉印证） |
| 机制验证 | 合成分析、相关/回归、环流异常场诊断、显著性检验 |
| 团队 | 5 人：组长（成员A）+ 成员B、C、D、E |
| 当前第一优先级 | **打通目标变量 Y 的数据链路**，形成"日期 → 区域 Tmax → 距平 → H"的可靠时间序列表 |

## 五、怎么使用这份规划书

1. **先读 02**：它是全项目的"主干"，其余文件都是主干上某个环节的展开。
2. **遇到看不懂的名词**：直接查 09，词典按"一句话解释 / 在本项目中的作用 / 常见误区"三段式编写。
3. **每完成一个阶段**：用 10 里的检查清单自检，并在组会上对照 02 的里程碑验收标准打勾。
4. **分工调整**：08 里的姓名一栏用「成员A—成员E」占位，确定人员后直接替换即可，
   职责边界与交付物不随人名变化。
5. **本规划书是活文档**：任何方案变更（如研究区范围、时段、变量集合变更）
   必须同步修改对应文件，并在 02 的"变更记录"中登记。

## 六、与原始材料的关系

- `plans.ipynb` 给出的是**研究闭环**与**执行顺序**（文献调研 → 因子库 → 数据 →
  样本 → 基线+ML → 滚动验证/消融/SHAP → 冻结 → 独立年份检验 → 极端高温二阶段 → 机制诊断）。

  （研究目标、技术路线 9 条、Y 的定义、X 的定义、不同变量日统计方式、
  样本表设计、模型分层、训练/验证/测试划分、评价指标与表格模板、
  SHAP 与物理机制验证、现阶段最优先任务）。
- 本规划书在此基础上补齐了原件未展开的部分：**明确的目标体系、阶段与里程碑、
  5 人分工与接口约定、极端事件评价细节、风险与质量保障、以及完整的术语词典**。
