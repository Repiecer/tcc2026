## 二、阶段质量检查清单（QA Checklist）

> 使用方式：每进入下一阶段前，由阶段主责人逐条打勾，组会上抽查。

### P0 立项与方案定稿

- [ ] 研究区经纬度范围已明确并写入配置
- [ ] 研究时段（年份 + 月份）已明确
- [ ] 变量清单已定稿，每个变量都有对应的物理假设
- [ ] 目标定义（日 H / 周平均 H）已选定
- [ ] 数据集划分方案已确定
- [ ] 代码仓库、`uv` 环境、目录结构就绪
- [ ] 因子—物理假设表已产出

### P1 数据与目标变量 Y

- [ ] 10 项质控清单全部通过（见 03 文件第五节）
- [ ] 数据质量报告已产出（时间序列图 + 异常值统计 + 区域平均合理性检查）
- [ ] `y_series.parquet` 无缺测、无重复、时间轴连续
- [ ] 各日历日 H 的均值≈0、标准差≈1
- [ ] 2013、2017、2022 等极端高温年在 H 上明显偏正
- [ ] 气候态计算基准期已明确且无泄漏
- [ ] `docs/data_dictionary.md` 已更新全部变量

### P2 样本库

- [ ] 四套样本表（lead 1—4）结构一致、列名一致
- [ ] 每行都有 `issue_date`、`target_start`、`target_end`、`lead_week`
- [ ] `check_leakage()` 全部断言通过
- [ ] 随机抽 100 行人工核对，通过率 100%
- [ ] 样本量、缺失值比例、各特征分布已统计并记录
- [ ] 训练/验证/测试年份无交集

### P3 建模

- [ ] 气候态与持续性基线已实现并产出结果
- [ ] 三类模型均在同一评估协议下运行
- [ ] 超参数只在验证集上确定
- [ ] 滚动验证曲线已产出，技巧年际分布已检查
- [ ] 训练—验证泛化间隙已检查（无明显过拟合）
- [ ] 实验日志记录了配置、种子与指标

### P4 消融与冻结

- [ ] A—E 五组消融各提前期结果齐全（5 × 4）
- [ ] 消融实验中除变量集合外，其他设置完全一致
- [ ] SHAP 与 Permutation Importance 结论已交叉对比
- [ ] 最终因子集合已确定并写入配置
- [ ] `configs/frozen_v1.yaml` 已生成并记录哈希
- [ ] 组长已复核冻结配置并签字确认

### P5 独立检验与极端事件

- [ ] 测试集只被调用一次（实验日志可证）
- [ ] 连续指标齐全，且含置信区间
- [ ] 相对气候态与持续性基线的技巧评分均已计算
- [ ] 极端阈值仅由训练期确定
- [ ] 分类指标齐全（含 HSS/TSS），未使用 Accuracy 作为主要指标
- [ ] 两条二阶段路线已对比
- [ ] 结果表包含全部四个提前期

### P6 机制与成果

- [ ] SHAP / Permutation / 消融三重证据已并列呈现
- [ ] 关键因子汇总表含证据强度分级
- [ ] 机制诊断含显著性检验与年代际稳定性检验
- [ ] 结论表述区分"统计相关"与"物理因果"
- [ ] 所有图表均可由脚本一键生成
- [ ] 在新环境中从零复现主结果成功
- [ ] 负结果与局限已如实写入报告

## 三、代码与数据规范

| 项目 | 规范 |
| --- | --- |
| 代码位置 | 正式代码只在 `src/tcc/`；notebook 仅用于探索 |
| 配置 | 所有参数进 `configs/*.yaml`，禁止硬编码 |
| 路径 | 用相对路径或配置文件中的路径变量，禁止绝对路径 |
| 随机性 | 所有随机过程显式设置并记录种子 |
| 数据入 git | **禁止**；`data/`、`models/`、`results/runs/` 忽略 |
| 大文件 | 用压缩格式（parquet 优先于 csv；NetCDF 用压缩编码） |
| 日志 | 每次运行输出到 `results/runs/{run_name}/`，含配置副本与指标 JSON |
| 函数文档 | 关键函数写明输入输出、单位与假设 |
| 评审 | 涉及样本表生成、指标计算、数据划分的代码必须他人评审 |

## 四、数据共享与安全

- ERA5 数据通过 CDS 下载，**遵守 Copernicus 许可与引用要求**，论文与报告中注明数据来源；
- CDS API Key 等凭据**不入 git**，用环境变量或本地配置文件；
- 论文与结题报告中公开**代码与处理后的数据表**（若数据许可允许），原始数据给出下载脚本与说明。

## 五、学术规范

| 要求 | 说明 |
| --- | --- |
| 如实报告 | 不选择性汇报；负结果与不显著结果同样写入 |
| 区分相关与因果 | 全文遵循 07 文件的表述规范 |
| 数据引用 | 明确标注 ERA5 版本、下载时间与处理方式 |
| 方法透明 | 超参数、划分方式、阈值来源全部可查 |
| 图表规范 | 坐标轴标注单位；显著性用标准符号；色标考虑色盲友好 |
| 复现声明 | 报告中给出复现主结果的命令与配置文件名 |
