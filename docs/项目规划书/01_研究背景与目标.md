## 一、研究背景

### 1.1 气候背景：长江中下游是高温高影响区

长江中下游地区（含四川盆地以东的长江干流及两湖平原、江淮地区）是我国夏季高温
最频繁、持续时间最长的区域之一。该区域高温具有三个显著特征：

1. **与西太平洋副热带高压（西太副高，WPSH）异常密切相关**——副高偏强、偏西、
   偏北时，区域受下沉气流控制，晴空辐射增强、下沉增温，形成持续高温；
2. **与陆面干湿状态强耦合**——前期土壤偏干会抑制蒸散（潜热），使本该用于
   冷却地表的能量转为感热，近地面气温进一步升高，并因土壤湿度具有较长的
   "记忆"而自我维持；
3. **社会经济影响大**——高温直接冲击电力负荷、农业生产、人体健康与水资源调度。

### 1.2 科学缺口：延伸期是"预测空档"

- **中期天气预报**（1—10 天）：主要靠初值，天气模式已较成熟；
- **季节预测**（1 个月以上）：主要靠海温、外强迫等慢变信号；
- **延伸期（10—30 天）**：正好夹在两者之间，被称为"可预报性沙漠/预测空档"。

延伸期高温预测的可预报性来源主要包括：**土壤湿度记忆**、**MJO/BSISO 等热带
季节内振荡**、**西太副高与中高纬环流的持续性异常**、**海温异常的缓慢演变**。
本项目的核心动机就是：**用机器学习去挖掘这些人眼难以线性分离的前兆信息，
在这一时间尺度上做出可检验、可解释的预测。**

### 1.3 方法背景：机器学习擅长表格型气象数据，但必须"防作弊、可解释"

- 机器学习（Random Forest、XGBoost 等）善于从高维、非线性、相互关联的
  气象因子中提取信号，适合延伸期这种"信号弱、因子多"的问题；
- 但气象时间序列存在**强自相关**和**时间信息泄漏**风险，若随机打乱划分数据集，
  会得到虚高的技巧分数；
- 同时，纯"黑箱"模型无法回答"为什么"，因此必须引入 **SHAP** 等可解释性工具，
  并用**气候动力学诊断**验证其合理性。

> 本项目的方法论立场：**先物理假设、后数据挖掘；先简单基线、后复杂模型；
> 先独立检验、后机制解释。** 任何一步顺序颠倒都会损害结论可信度。

## 二、拟回答的科学问题

- **SQ1（可预测性）**：长江中下游暖季高温指数 H 在提前 1—4 周尺度上
  是否存在可被机器学习稳定捕捉的可预测信号？其技巧在多大程度上超过
  气候态与持续性基线？
- **SQ2（关键因子）**：哪些前期大气—陆面因子对提前 1—4 周的高温预测贡献最大？
  不同提前期的主导因子是否发生转换（例如近周以环流为主、远周以陆面记忆为主）？
- **SQ3（极端事件）**：连续预测结果经过阈值化/二阶段处理后，
  对极端高温事件的识别与预警能力（Recall、F1、HSS）如何？
  是否优于直接对极端与否做分类？
- **SQ4（物理合理性）**：模型识别出的关键因子能否用已知气候动力学机制解释？
  例如"前期土壤偏干 → 潜热减少、感热增强 → 高温增强"这条链条是否成立且显著？

## 三、项目目标

### 3.1 总目标

建立一套**可复现、可检验、可解释**的长江中下游暖季高温延伸期（1—4 周）
预测流程：从 ERA5 多要素资料出发，构建标准化高温指数目标序列，
建立从基线到机器学习的完整模型体系，通过独立年份检验与极端阈值检验
量化预测能力，并用 SHAP 与气候诊断阐明关键预测因子的物理意义。

### 3.2 分目标（可验收）

| 编号 | 分目标 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| G1 | 打通目标变量数据链路 | 1981—2025 年 5—8 月长江中下游区域 Tmax 与 H 的逐日时间序列表 | 无缺测断点；季节循环与年际变化符合已有认知；通过物理范围与时间对齐检查 |
| G2 | 建立多提前期样本库 | 提前 1/2/3/4 周的四套机器学习样本表（X, Y） | 每行样本可追溯到具体发布时刻与目标时段；重复抽取 100 行人工核对无未来信息 |
| G3 | 建立分层模型体系 | 气候态、持续性、Linear/Ridge、Random Forest、XGBoost 五类模型的训练与预测代码 | 五类模型在同一评估协议下产出可比结果表 |
| G4 | 完成训练/验证/测试与滚动验证 | 调参记录、滚动验证曲线、独立年份测试结果表 | 超参数只在验证集上确定；测试集只使用一次；随机种子与配置可复现 |
| G5 | 完成因子分组消融实验 | A—E 五组消融结果表（技巧随变量类别加入的变化） | 每组仅改变输入变量集合，其余设置完全一致 |
| G6 | 完成极端高温二阶段识别/预警 | 极端事件评价表与预警模块 | 阈值仅在训练期确定；给出 Precision/Recall/F1/HSS 及相对基线的提升 |
| G7 | 完成可解释性与机制验证 | SHAP 汇总图、分组贡献分析、合成分析/相关回归/环流诊断图 | 三重证据（SHAP、Permutation、消融）结论一致性说明；机制链条有显著性检验支撑 |
| G8 | 成果产出 | 结题报告、论文初稿、答辩材料、可复现代码库 | 代码可在新环境一键复现主结果；结论与图表一一对应 |

## 四、预期成果

1. **数据集类**：1981—2025 年长江中下游暖季标准化高温指数 H 时间序列；
   提前 1—4 周的多变量预测因子样本库（含数据字典）。
2. **方法类**：一套开源的"基线 → 机器学习 → 消融 → SHAP → 机制诊断"的
   延伸期高温预测流程代码（Python，`uv` 管理环境，配置可复现）。
3. **科学结论类**：
   - 提前 1—4 周高温预测技巧的定量估计及其相对基线的提升；
   - 关键预测因子清单及其随提前期的变化规律；
   - 极端高温事件的预警能力评估；
   - 关键因子物理机制的诊断证据。
4. **应用类**：可输出"未来第 1—4 周偏热程度 + 极端高温风险等级"的
   简易预警原型（离线运行，用于演示与结题答辩）。

## 五、创新点

1. **样本构建的严格性**：把"预测发布时刻—目标时段"的时间对齐规则显式化，
   从数据层面杜绝未来信息进入模型，使技巧评估可信。
2. **从简单到复杂的证据链**：不是"直接上一个 XGBoost"，而是用气候态、
   持续性、线性模型逐层对照，明确回答"机器学习究竟带来了多少增量技巧"。
3. **分组消融而非单变量重要性**：用 A→E 的变量分组递进实验，
   解决高相关气象变量互相"分摊贡献"导致的重要性排序失真问题。
4. **连续预测 + 极端二阶段的组合设计**：先解决"偏热多少"，
   再解决"是否达到极端"，比直接做二分类更充分利用样本信息。
5. **可解释性与物理机制的双向校验**：SHAP 给线索、气候动力学给判据，
   避免把统计相关误读为因果。

## 六、非目标（明确不做的事，防止范围蔓延）

- **不做**业务化实时预报系统的工程化部署（只做离线可演示原型）。
- **不做** 1981 年以前的历史重建或未来情景预估（不涉及 CMIP 情景数据）。
- **第一阶段不做** LSTM/Transformer 等深度序列模型——理由见
  [`05_模型体系与实验设计.md`](05_模型体系与实验设计.md)；
  待前三层模型流程完全跑通后，可作为拓展方向。
- **不声称**因果关系：SHAP 贡献只作为"统计线索"，因果结论必须由
  合成分析、回归诊断与已知物理机制共同支撑。
- **不使用**目标时段及未来的任何观测信息作为预测因子。
