# OLR（向外长波辐射）指数 数据字典

由 `scripts/standardize_olr.py` 生成。

## 用途：H4 地表能量因子的替代量

拿不到 `ssrd`（短波辐射），改用 OLR。两者都回答同一个问题：**"天有多晴"**。

```
晴空（地面热、大气干）  ->  向外长波辐射大  ->  OLR 高
有云 / 深对流（云顶冷） ->  向外长波辐射小  ->  OLR 低
```

云顶温度很低（可低于 -40 °C），按斯特藩-玻尔兹曼定律，冷的东西发射少。
所以 **OLR 是云量与对流的经典代理量**，与云量负相关、与高温正相关。

## ⚠️ 符号约定（本项目已修正）

Planette 里这个变量名叫 `olr`，但**实测全为负值**（-322 ~ -128 W/m²），
说明它其实是 ERA5 的 `ttr`（top net thermal radiation，**净向下为正**）。

`src/tcc/fetch_olr.py` 已用 `scale=-1` 翻成标准 OLR（**向上为正**）。实测验证：

| 年份 | 类型 | OLR 域平均 | 与 H 的日相关 |
|---|---|---|---|
| 1993 | 湿凉年 H=-0.62 | 220.5 W/m² | +0.242 |
| 2022 | 干热年 H=+0.79 | **243.0 W/m²** | +0.445 |

越热 OLR 越大，物理正确。**若不翻符号，后面所有相关分析的正负号都会反。**

## 输出文件 / 区域

| 文件 | 变量 | 单位 |
|---|---|---|
| `data/proc/olr_indices.nc` | `olr_index` | 无量纲 |
| `data/proc/olr_anomaly.nc` | `olr_anom` | W m-2 |
| `data/proc/olr_norm_params.nc` | `clim`, `sigma` | W m-2 |

区域：`yrb`（28-34°N, 110-122°E），完整 0.25° 网格（25×49）。
处理参数与其它变量一致（11 天窗口、基准期 1981-2015、季节日编号、sigma 下限）。

## 已知事项

- OLR 与 TP 在机制上**部分重复**（少雨 = 少云 = OLR 高），模型里注意共线性。
  但实测两者对不同提前期的贡献不同，值得分别进入消融 C 组与 B 组。
- 原计划用的 `ssrd` 走 Open-Meteo，但 **ERA5-Land 不提供辐射变量**
  （实测 48/48 全 null）。已改用 `models=era5` 修好（实测 0% NaN、均值 212.4 W/m²），
  但只下了 1 年做验证，其余 44 年未下。
  **结论：OLR 已能替代 ssrd 的作用，ssrd 不再必需。**
- `slhtf`（潜热通量）Open-Meteo 与 Planette 都不提供，已放弃；
  改用 `swv3` 深层土壤湿度作为这条机制链的替代量（效果更好）。
