# SWVL1（表层土壤体积含水量）指数 数据字典

由 `scripts/standardize_swvl1.py` 生成。

## 输出文件

| 文件 | 变量 | 含义 | 单位 |
|---|---|---|---|
| `data/proc/swvl1_indices.nc` | `swvl1_index` | 标准化指数 | 无量纲 |
| `data/proc/swvl1_anomaly.nc` | `swvl1_anom` | 距平 | m3 m-3 |
| `data/proc/swvl1_norm_params.nc` | `clim`, `sigma` | 逐日历日气候态与标准差 | m3 m-3 |

维度 `(index, time)`，`index` 取值 `yrb`。

## 区域定义

| 指数 | 纬度 | 经度 | 含义 |
|---|---|---|---|
| `yrb` | 28-34°N | 110-122°E | 整个研究区 |

## 处理参数

| 项目 | 取值 |
|---|---|
| 源数据 | `data/raw/swvl1/swvl1_YYYY.nc` |
| 时间范围 | 1981-2025 年，仅 5-8 月（123 天/年，共 5535 天）|
| 目标网格 | 与 `data/raw/tmax` 一致：28-34°N, 110-122°E，13×25 / 0.5° |
| 网格提取 | 最近邻索引精确提取，匹配误差 0（0.25° 是 0.5° 的超集，无插值）|
| 区域平均 | `cos(纬度)` 面积加权 |
| 气候态窗口 | 以日历日为中心 ±5 天（共 11 天）滑动窗口 |
| 窗口平滑方式 | 对（样本数、样本和、平方和）求和后再相除，等价于窗口内样本池化 |
| 气候态基准期 | 1981-2015（**只用训练期，冻结使用**）|
| sigma 下限 | 全季平均 sigma 的 0.5 倍 |
| 标准化公式 | `z = (index - clim) / sigma` |

## ⚠️ 已知问题：数据源混用

`data/raw/swvl1/` 里混了两种源与两种网格：

| 来源 | 文件数 | 网格 | 产品 |
|---|---|---|---|
| Planette ERA5 Archive | 25 | 0.25°（25×49）| ERA5 swv_1 |
| Open-Meteo Archive | 20 | 0.5°（13×25）| ERA5-Land swvl1 |

**ERA5 与 ERA5-Land 的表层土壤湿度是不同产品**，土壤层定义与陆面模式都不同，
存在系统性差异。本脚本把两者都精确提取到同一 0.5° 网格（匹配误差 0，无插值损失），
但**源产品混用这个事实无法通过后处理消除**。

**影响**：气候态（clim/sigma）在混源年份边界处可能有不连续，
下游模型可能把「换源」误当成真实信号。

**建议**：日后统一用 Planette 重下全部 45 年（无配额、可一次跑完）：

```bash
cd src/tcc && ../../.venv/bin/python fetch_swvl1.py --years 1981-2025 --months 5-8 --force
```

重下后本脚本无需修改，直接重跑即可。

## 已知事项

- 物理假设 H2：前期土壤偏干 → 蒸散减弱 → 潜热减少 → 感热增强 → 高温增强，
  预期**负相关**。注意这条链条存在**双向因果**（高温本身也会抽干土壤），
  因此 SHAP 显示该因子重要**不能直接当作因果证据**，需结合 TP 与 SLHTF 交叉验证。
- 源数据有极小的负值（约 -7e-6 m3/m3），是浮点换算的舍入噪声，物理上等于 0。
- 本脚本不做累积（土壤湿度是状态量，不是累积量）；TP 那种累积量要用不同处理。
