## 二、这批案例告诉我们的六条规律

### 规律 1：获奖作品的骨架是"真痛点 → 数据/模型 → 可解释 → 落地/对策"

几乎每一个国奖作品都不是"我跑了一个模型"，而是：

```
行业/社会真问题  →  数据与建模  →  可解释/机制  →  对策、平台或产品
```

例如杭师大作品最后落在"内涝预警平台 + 景观优化对策"，
南大作品最后落在"电网主动防御调度"，川农作品最后落在"小程序"。
**我们的规划书里"极端高温二阶段预警等级 + 机制诊断"正是这个骨架的后两环，
需要在答辩材料中被明确强调，而不是只报 RMSE/R²。**

### 规律 2："气象 + AI"在挑战杯里有三条成熟路线

| 路线 | 代表案例 | 特点 | 我们的位置 |
| --- | --- | --- | --- |
| **A. 探测/识别类** | 南大 EchoPrint、兰大智析风云、内蒙云雷达杂波 | 给雷达/卫星数据做智能识别，指标明确（准确率），易讲清楚 | 不适用 |
| **B. 预测/评估类** | 杭师大热岛-雨岛、南大电网风险、湖州师院内涝预报 | 做预测再评估影响，**最贴近我们** | ✅ **我们就走这条** |
| **C. AI+ 产品类** | 川农天气智农小程序 | 强调可用性与交互，技术门槛相对低 | 可作为结题演示形态参考 |

### 规律 3：**"极端事件识别"是一个被反复验证的得分点**

南大台风项目在简介里直接点明：

> "纯数据驱动的人工智能方法由于**样本不平衡**等原因倾向于**低估强台风**"

这与我们规划书
[`06_评价体系与极端高温二阶段.md`](../notebooks/项目规划书/06_评价体系与极端高温二阶段.md)
里写的"回归模型向均值收缩 → 漏报极值 → 需要二阶段专门处理"**几乎完全同构**。
区别只是：他们用台风强度，我们用高温指数 H。

**→ 结论：我们的"二阶段极端高温识别"不是画蛇添足，而是国奖级作品公认的技术难点，
应当作为核心创新点来写，而不是附赠功能。**

### 规律 4：可解释性可以作为卖点，而不是短板

EchoPrint 的简介把"**高准确率、高实时性、强可解释性且具备业务化应用能力**"并列写成成果。
说明评审认可"能解释"本身就是价值。
我们的 SHAP + 合成分析 + 环流诊断三重证据体系，可以在答辩中占据同样的位置。

### 规律 5：好作品往往是"从一篇论文长出来的"

杭师大案例的成长链条非常清晰：

```
《基于景观组分和空间构型的未来城市热岛预测研究——以杭州市为例》（校"精进杯"一等奖）
        ↓ 扩展研究对象与落地场景
《城市"湿热病"预诊医生——基于城市多维形态的热岛-雨岛效应模拟及调控对策研究》（国赛特等奖）
```

**→ 对应到我们：Y 链路 + 提前 1—4 周预测 + 极端二阶段，
本身就是"从一张高质量的数据序列表长成一个作品"的路径。
不必一开始就追求大而全。**

### 规律 6：跨学院组队与"揭榜挂帅"是两条捷径

- **跨学院组队**：南信大特等奖是**软件学院 × 大气学院**联合组队——
  数据工程能力 + 气象专业判断力。我们的 5 人分工如果只来自同一专业，
  可以考虑引入计算机/统计方向的同学补强工程侧。
- **揭榜挂帅**：由国家气象信息中心出题、南信大揭榜拿下特等奖。
  这类赛道**题目明确、评价标准由发榜方给出**，比自由选题更容易对标。
  第十九届的选题里就有气象相关信息类题目（见案例 06）。

## 三、必须警惕的三条"反面教训"

| 风险 | 案例中的信号 | 我们的应对 |
| --- | --- | --- |
| **只做"调包跑模型"，无物理内涵** | 数据库中大量条目止步于校赛/省赛，标题多是"基于 X 算法的 Y 预测系统" | 规划书 [07](../notebooks/项目规划书/07_可解释性与物理机制验证.md) 的机制诊断是必须完成项，不是可选项 |
| **没有一个能打动人的"痛点故事"** | 国奖作品的简介第一句都在讲现实问题（高温、内涝、电网、防灾） | 答辩材料要把"长江中下游高温 → 电力/农业/健康"的影响写进第一页 |
| **指标好看但不可复现/不可信** | 优秀作品都强调"业务化""平台部署""软著专利" | 我们的防泄漏五条铁律 + 可复现打包，要主动讲出来作为方法学亮点 |

## 四、扫描结论：这个选题在"大挑"里是**空白区**

我把挑战杯官方"人才项目库"（镜像站 <https://www.z-legko.com/xmk/project/list/project/>）
的 **238 页、共 4760 条获奖项目记录**全部抓取后按关键词检索，结果：

| 检索词 | 命中数 | 说明 |
| --- | --- | --- |
| 热岛 / 城市热环境 / 微气候 | 1 | 云南艺术学院"村落微气候量化"（非预测） |
| 高温 / 热浪（作为**气象预测对象**） | **0** | 命中的"高温"全部是材料、冶金、农业胁迫等无关领域 |
| 气温预测 / 温度预测 | 0 | — |
| 延伸期 / 次季节 / 季节内 / MJO | **0** | — |
| 土壤湿度 / 陆气相互作用 / 蒸散 | **0** | — |
| 副高 / 环流 / 位势高度（气象意义） | 0 | 命中的"高压"全部是电力高压 |

> 注：该镜像库共 4760 条，覆盖第十三届至第十九届的部分获奖记录（其中国赛/省赛混合），
> 并非全部参赛作品，因此结论应表述为"**在该库可检索范围内**，本课题方向近乎空白"。

**这个结论有两个含义：**

1. **机会**：方向稀缺 → 差异化明显，不容易与别人撞题；"首次把延伸期高温预测引入挑战杯"本身就是一个可以讲的故事。
2. **风险**：没有现成对标 → 评审可能不熟悉"延伸期""标准化高温指数 H"这类概念，
   必须在作品简介与答辩中**用通俗语言解释清楚**（这也是我们规划书
   [`09_概念词典.md`](../notebooks/项目规划书/09_概念词典.md) 的价值所在）。
