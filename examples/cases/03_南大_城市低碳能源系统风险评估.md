## 二、项目做了什么（官方简介要点）

> 近年来，全球气候变化加剧导致极端天气增多，台风、洪水、极寒等自然灾害的发生
> 对城市低碳能源系统安全稳定运行带来极大挑战。因此，**提前预测和评估极端天气
> 对城市电网造成的风险**，及时采取主动防御措施，成为提升城市能源系统韧性、
> 保障居民用电安全的关键手段。
>
> 团队结合大气科学的学科优势与电网安全保障的现实需求，
> 基于**高时空分辨率的数值模式天气预报技术**，构建了
> **高精度、长时效的电网高影响天气预报模型**，实现了城市低碳能源系统
> **发电、输电、用电三端**的极端天气影响评估与统筹决策调度。
>
> ——南京大学大气科学学院官网新闻稿

结构拆解：

```
极端天气（气象）  →  电网高影响天气预报模型  →  发电/输电/用电三端影响评估  →  统筹决策调度
   痛点                核心方法                    行业接口                    落地价值
```

## 三、为什么这个案例对我们重要

### 3.1 它示范了"气象预测如何变成一个有分量的作品"

单纯报"我的模型 RMSE 是多少"很难打动非气象背景的评审。
这个作品给出了标准答案：**把预测接到一个高价值行业上**。

我们的对应关系：

| 他们的 | 我们可以对应的 |
| --- | --- |
| 极端天气 → 电网风险 | 延伸期高温 → 电力负荷 / 农业高温热害 / 人体健康风险 |
| 高影响天气预报模型 | 长江中下游高温指数 H 的 1—4 周预测模型 |
| 三端影响评估 | **分等级高温预警**（蓝/黄/红），对应不同应对措施 |
| 统筹决策调度 | 预警原型的输出报表 |

> 注意：**不要真的去做电力负荷建模**（那是另一个课题）。
> 正确做法是：在"讨论与展望"里用一小段说明"本预测结果可直接服务于
> 电力调度、农业高温热害预警等场景"，而不是把它做成第二个主线。

### 3.2 "长时效"是他们的关键词，正是我们的主场

简介特意强调"**高精度、长时效**"。延伸期（1—4 周）本身就是
"比中期天气长、比季节预测短"的时效空档，**"长时效"是我们天生的标签**，
应当在标题与简介中突出。

### 3.3 校企联合指导的模式

指导教师之一来自**南京浦蓝大气环境研究院有限公司**。
说明挑战杯作品鼓励"高校 + 业务/产业单位"联合指导，
这既提升应用可信度，也便于获取真实业务数据与评价标准。

**对我们的启示**：可以考虑邀请**气象局/气候中心**的业务人员作为
第二指导教师或顾问，这对"揭榜挂帅"类赛道尤其重要（见案例 06、07）。

## 四、可借鉴的具体做法

1. **作品标题里点明"评估"与"防御"**——不只说"预测"，
   而是把"评估"和"应对"写进名字，体现完整闭环。
2. **画出"三端"式结构图**——他们的"发电/输电/用电"三分法让评审一眼看懂覆盖面。
   我们可以画"数据链路 / 预测模型 / 预警服务"三段图。
3. **强调数值模式/物理基础**——他们用"高时空分辨率的数值模式天气预报技术"
   表明不是纯数据挖掘。我们的对应表述是"基于 ERA5 再分析资料与
   陆气相互作用物理假设的因子体系"。
4. **多人多导师团队**：7 名学生 + 2 名导师（含产业导师），
   说明团队规模与指导阵容也是评审考量之一。

## 五、不能照搬的地方

| 他们的做法 | 我们的差异 |
| --- | --- |
| 用数值模式预报（NWP）输出做输入 | 我们用 ERA5 再分析做**历史回报检验**，不涉及实时 NWP 数据链路 |
| 目标是最短时效内的极端天气（台风、洪水、极寒） | 我们的目标是**延伸期高温**，时效更长、信号更弱 |
| 行业端（电网）数据与模型 | 我们没有行业数据，只能做影响层面的定性对接 |
