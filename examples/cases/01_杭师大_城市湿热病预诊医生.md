## 二、项目做了什么

根据学校新闻稿与挑战杯官方项目库条目，作品的核心内容：

1. **研究对象**：城市"湿热病"——即**热岛效应与雨岛效应**的复合影响。
2. **技术路线**：
   - 应用**多维城市形态表征技术**刻画城市下垫面；
   - 应用**人工智能算法**；
   - **建立高温和内涝预测模型**；
   - 从**城市景观优化**角度提出治理策略。
3. **成果体量**：
   - 团队学生以第一作者发表学术论文 **8 篇**，其中中科院一区 TOP 期刊 **3 篇**，
     累计影响因子 **44.824**；
   - 申请发明专利 **3 项**，注册软件著作权 **6 项**。
4. **落地应用**：在杭州第十九届亚运会期间，团队承担**奥体中心等多个场馆的内涝预警平台**建设。
5. **专家评价**：中国工程院院士潘德炉、中国科学院院士杨树锋等给予高度评价。
6. **备赛周期**：自校内选拔赛起，历时近 300 个日夜。

## 三、为什么这个案例对我们最有参考价值

### 3.1 选题结构高度相似

| 维度 | 杭师大作品 | 我们的课题 |
| --- | --- | --- |
| 气候/环境现象 | 城市热岛 + 雨岛 | 长江中下游区域高温 |
| 预测对象 | 高温、内涝 | 标准化高温指数 H |
| 方法 | 城市形态表征 + 人工智能算法 | ERA5 多要素 + 机器学习 |
| 空间尺度 | 城市 | 区域（长江中下游） |
| 时间尺度 | 未在简介中明确（偏诊断/预测） | **延伸期 1—4 周（更聚焦、更难）** |
| 产出 | 预测模型 + 调控对策 + 预警平台 | 预测模型 + 极端预警 + 机制解释 |

**关键差异**：他们的时间尺度更宽泛，而我们把时间尺度**锁定在"延伸期"**，
这既提高了科学难度，也让创新点更锐利——但也意味着
**必须把"延伸期是什么、难在哪"解释得非常清楚**（见案例总览第四节的"风险"）。

### 3.2 "从一篇论文长成一个作品"的路径

```
校"精进杯"一等奖：《基于景观组分和空间构型的未来城市热岛预测研究——以杭州市为例》
        ↓ 拓展对象（加雨岛/内涝）、拓展落地场景（亚运会场馆）、沉淀成果（论文/专利/软著）
国赛特等奖：《城市"湿热病"预诊医生》
```

**对我们的启示**：我们的课题同样可以按"最小可发表单元 → 完整作品"来组织：

```
第一步：1981—2025 长江中下游标准化高温指数 H 序列（数据贡献）
第二步：提前 1—4 周预测技巧的定量评估（方法贡献）
第三步：极端高温二阶段识别 + 关键因子机制诊断（应用+科学贡献）
```

不要一上来就想做"大而全"的实时预警系统。

### 3.3 值得直接抄的三件事

1. **把"对策"写进标题**：标题里出现"调控对策研究"，
   表明作品不只是分析，还给出解决方案。我们的标题/简介里应体现
   "**预警**"而不只是"预测"。
2. **量化成果体量**：论文数、影响因子、专利、软著——评审需要"看得见的产出"。
   我们规划书 G8 的"结题报告 + 论文初稿 + 可复现代码库"应尽早启动。
3. **真实落地背书**：亚运会场馆预警平台是最强的可信度来源。
   我们的对应物可以是"用 2021—2025 年独立检验结果说明模型在近年真实高温年（如 2022）中的表现"。

## 四、不能照搬的地方

| 他们的做法 | 我们不能照搬的原因 |
| --- | --- |
| 城市尺度、景观格局驱动 | 我们做**区域尺度的大气—陆面过程**，驱动因子是环流与土壤湿度，不是城市形态 |
| 用雨洪管理模型算径流 | 我们的目标是气温，不涉及水文模型 |
| 8 篇 SCI 一区论文的产出强度 | 时间与人力不匹配；我们应保证 **1—2 篇扎实的论文 + 完整可复现流程** |
