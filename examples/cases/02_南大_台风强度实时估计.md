## 二、项目做了什么（官方简介要点）

> 台风是影响我国最为严重的自然灾害之一，其精确的强度估计对防灾减灾至关重要。
> 传统方法复杂主观，**纯数据驱动的人工智能方法由于样本不平衡等原因倾向于低估强台风**。
> 针对这一瓶颈，本项目发展了**台风眼区特征识别模型**，并进一步通过
> **耦合眼区时序特征等台风发展关键物理信息**，构建了高精度的台风强度实时估计系统，
> **改进了超强台风强度低估的问题**，为台风防灾减灾决策提供可靠技术支撑。
>
> ——南京大学大气科学学院官网新闻稿

技术要点归纳：

1. **问题**：纯数据驱动方法的**样本不平衡**（强台风样本极少）导致**极值低估**；
2. **解法一**：眼区特征识别模型（结构化特征提取）；
3. **解法二**：**耦合物理信息**——把台风发展过程中的关键物理量（眼区时序特征）显式加入模型；
4. **结果**：超强台风强度低估问题得到改进，形成"实时估计系统"。

## 三、与我们课题的对应关系（本案例最重要的价值）

这是全部案例中**方法论同构度最高**的一个。对照表：

| 维度 | 南大台风项目 | 我们的高温项目 |
| --- | --- | --- |
| 预测/估计对象 | 台风强度（连续量） | 标准化高温指数 H（连续量） |
| 数据不平衡来源 | **强台风样本极少** | **极端高温样本极少**（90%/95% 分位以外） |
| 纯数据驱动的失效模式 | **低估强台风**（向样本均值收缩） | **低估极端高温**（回归模型向均值收缩、树模型不能外推） |
| 解决思路 | 显式耦合**物理信息**（眼区时序特征） | ① 分位数回归 / 样本加权；② 加入**物理机制因子**（土壤湿度、Z500 等） |
| 评价关注点 | 强台风强度不被低估 | 极端事件的 **Recall / F1 / HSS**，而非整体 RMSE 好看 |
| 呈现方式 | 实时估计系统 | 二阶段预警等级 + 预警原型 |

**结论：他们把这个难点写进了作品简介的第一段，并作为核心创新点。
我们的规划书应当做同样的事。**

## 四、可借鉴的具体做法

1. **把"失效模式"写在最前面**
   简介第一句讲灾害重要性，第二句立刻讲"现有 AI 方法有系统性缺陷"，
   第三句讲"我们怎么解决"。这个三段式极其适合答辩开场。

2. **"物理信息 + 数据驱动"是评审认可的范式**
   纯机器学习容易被质疑"调包、没物理"。他们用"耦合眼区时序特征"这一句话
   就把项目从"调包"提升为"有物理约束的建模"。
   我们的对应表述可以是：
   > "在数据驱动模型的基础上，引入前期土壤湿度记忆与副高环流异常等
   > **已知物理机制约束的预测因子**，并检验其贡献是否符合气候动力学预期。"

3. **"实时系统"这个包装值得学**
   把模型包成一个能演示的系统（哪怕离线），答辩效果远好于一堆散点图。
   我们规划书的 G8 已经包含"可输出未来 1—4 周偏热程度 + 极端风险等级的预警原型"。

4. **小团队也能拿特等奖**
   团队仅 3 名成员（同院系），说明**聚焦一个技术点做深**
   比人多摊大饼更有效。这对我们 5 人团队是个提醒：
   分工要清晰，但作品叙事必须围绕**一条主线**。

## 五、不能照搬的地方

| 他们的做法 | 我们的差异 |
| --- | --- |
| 台风强度是**观测估计**（同期的），不是提前预测 | 我们是**提前 1—4 周的预测**，时间信息泄漏风险高得多，必须严守防泄漏铁律 |
| 卫星云图等高频观测资料 | 我们用 ERA5 再分析月/日尺度资料 |
| 眼区特征这类强结构信号 | 高温是弱信号、多因子、缓变过程，物理信息耦合方式不同 |
