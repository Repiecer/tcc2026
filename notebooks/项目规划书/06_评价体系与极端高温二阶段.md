## 一、第一阶段：连续预测技巧评价

### 1.1 四个核心指标

设真实值为 `y_i`，预测值为 `ŷ_i`，样本量 `n`，`ȳ` 为真实值均值。

| 指标 | 公式 | 单位 | 含义 | 对什么敏感 |
| --- | --- | --- | --- | --- |
| **MAE**（平均绝对误差） | `(1/n) Σ \|y_i − ŷ_i\|` | 与 H 同（无量纲） | 平均偏差多大 | 对所有误差等权，稳健 |
| **RMSE**（均方根误差） | `sqrt( (1/n) Σ (y_i − ŷ_i)² )` | 与 H 同 | 典型误差量级 | **对大误差更敏感**（平方放大） |
| **R**（皮尔逊相关系数） | `cov(y,ŷ) / (σ_y · σ_ŷ)` | 无量纲，[−1,1] | 预测与真值的**同步变化**程度 | 只反映相关性，**不反映偏差与量级** |
| **R²**（决定系数） | `1 − Σ(y_i − ŷ_i)² / Σ(y_i − ȳ)²` | 无量纲，可为负 | 解释了目标方差的多少 | 综合；**可以为负**（比"直接用均值预测"还差） |

**必须一起看，不能只看一个**：

- R 很高但 RMSE 也很大 → 模型"跟得上变化"但整体偏移（可能系统偏差或量级压缩）；
- R² 很低但 RMSE 与 MAE 接近 → 目标本身方差小，模型虽准但没抓住变化；
- RMSE 远大于 MAE → 存在少量大误差（通常是极端年份），值得单独分析。

### 1.2 附加指标

| 指标 | 公式/说明 | 用途 |
| --- | --- | --- |
| **Bias（平均偏差）** | `(1/n) Σ (ŷ_i − y_i)` | 检验系统性高估/低估；树模型常表现为"向均值收缩" |
| **ACC（异常相关系数）** | 去气候态后的相关系数 | 气象领域常用；因 H 已是标准化距平，H 上的 R 即相当于 ACC |
| **技巧评分 Skill Score** | `SS = 1 − MSE_model / MSE_ref` | **相对基线的提升**；`SS > 0` 才说明比基线好 |
| **降幅百分比** | `(RMSE_ref − RMSE_model) / RMSE_ref × 100%` | 直观表达"相对基线降低了多少误差" |
| **标准差比** | `σ_ŷ / σ_y` | < 1 说明预测过于平滑（振幅压缩），是树模型与回归的常见问题 |

**参照基线**：
- `ref = 气候态`（`ŷ = 0`）→ 回答"有没有超出气候态的信息"；
- `ref = 持续性` → 回答"有没有超出'上周热这周也热'的信息"。

**两个技巧评分都要报**：只报相对气候态的提升容易高估工作的价值。

### 1.3 显著性检验与不确定区间

气象时间序列自相关强，**不能**直接把 `n` 代入常规显著性检验公式。

| 方法 | 用途 |
| --- | --- |
| **分块 bootstrap（block bootstrap）** | 按连续时间块（如整月或整年）重采样，估计 R、RMSE 的置信区间 |
| **有效自由度修正** | 按自相关系数折减自由度，得到保守的显著性判据 |
| **Diebold–Mariano 检验** | 检验两个模型的预测误差是否有显著差异（"XGBoost 真的显著优于 RF 吗？"） |
| **置换检验（permutation test）** | 打乱年份标签，构造"无技巧"的零分布，得到经验 p 值 |

**报告规范**：所有核心指标都给出**点估计 + 置信区间**，
例如 `R = 0.42 [0.28, 0.55]`，而不是孤零零一个数字。

## 二、第二阶段：极端高温识别与预警

### 2.1 为什么需要第二阶段

第一阶段模型输出的是连续值 H。但实际需求是**"会不会出现极端高温"**这一判断。
直接对连续预测做阈值转换存在两个问题：

1. 回归模型倾向于**向均值收缩**，预测的极值被系统性压低，
   直接用固定阈值会导致**漏报（Recall 低）**；
2. 极端事件本身**样本稀少**（95% 分位意味着只有 5% 的样本是正例），
   常规回归损失函数对这部分样本"不够在意"。

因此需要专门的二阶段处理来增强极端事件识别能力。

### 2.2 极端阈值的定义

| 项目 | 规定 |
| --- | --- |
| 阈值来源 | **只用训练期（1981—2015）的 H 分布**确定，然后冻结应用 |
| 阈值水平 | **90% 分位**（较宽，正例约占 10%）或 **95% 分位**（更严，正例约占 5%）；两个都算，便于对比 |
| 定义域 | 建议在**同一日历窗口内**（如整个 5—8 月）统一取，避免各日历日阈值抖动 |
| 显著性 | 可另定义"连续 3 天超阈值"为一次高温过程，用于过程级评价（可选） |

> ⚠️ **泄漏警告**：若用全部 45 年数据确定阈值，测试期的极值分布信息
> 会泄漏进来，导致指标乐观。必须只用训练期。

### 2.3 分类评价指标

以"极端（1）/ 非极端（0）"为正类，混淆矩阵：

| | 预测为极端 | 预测为非极端 |
| --- | --- | --- |
| **实际为极端** | 命中 TP | 漏报 FN |
| **实际为非极端** | 空报 FP | 正确否定 TN |

| 指标 | 公式 | 含义 | 在本项目中的意义 |
| --- | --- | --- | --- |
| **Precision（命中率/查准率）** | `TP / (TP + FP)` | 报出的极端里有多少是真的 | 预警的"可信度"，关系到是否"喊狼来了" |
| **Recall（召回率/查全率）** | `TP / (TP + FN)` | 真实的极端里抓到了多少 | **预警最重要的指标**，漏报代价高 |
| **F1** | `2PR / (P + R)` | Precision 与 Recall 的调和平均 | 综合指标，类别不平衡时比 Accuracy 可靠 |
| **ROC-AUC** | ROC 曲线下面积 | 排序能力（随机=0.5） | 阈值无关的整体判别能力 |
| **PR-AUC** | Precision-Recall 曲线下面积 | 不平衡数据下更敏感 | **类别极不平衡时首选** |
| **HSS**（Heidke Skill Score） | 见下 | 相对随机预测的技巧 | 气象领域标准的分类技巧评分 |
| **TSS**（True Skill Statistic） | `Recall + Specificity − 1` | 对命中与空报同等加权 | 不受类别比例影响，气象常用 |
| **BSS**（Brier Skill Score） | 相对气候态概率预报的改进 | 概率预报技巧 | 若输出概率型预警则使用 |
| **Accuracy（准确率）** | `(TP+TN)/n` | 整体正确率 | ⚠️ **本项目基本不用**：极端样本只占 5%—10%，全报"非极端"准确率也有 90%+，具有严重误导性 |

**HSS 定义**：

```
HSS = (TP + TN − E) / (n − E)
E = [(TP + FN)(TP + FP) + (TN + FP)(TN + FN)] / n     # 随机预测的期望正确数
```

**解读**：HSS > 0 表示优于随机；0.1—0.2 在延伸期尺度上已属可用；
HSS ≤ 0 说明模型没有分类价值。

### 2.4 两条实现路线（建议并行比较）

**路线 1：阈值转换法（简单、可解释）**

```
连续预测 Ŷ  →  若 Ŷ > θ 则判为极端，否则为非极端
```

- `θ` 在**验证集**上优化（可用 F1 或 TSS 最大化为目标），**不能**在测试集上调；
- 可选"概率化"：用训练集残差分布估计 `P(H > θ | Ŷ)`，输出概率而非硬判定；
- 优点：直接复用第一阶段模型，实现简单；
- 缺点：受回归收缩影响，Recall 往往偏低。

**路线 2：两阶段分类/加权（针对性强）**

| 方案 | 做法 |
| --- | --- |
| **样本加权回归** | 训练时为极端样本赋予更高权重，让模型更关注极端事件 |
| **分位数回归 / 极值损失** | 直接优化 90% 或 95% 分位（如 pinball loss），而不是均值；能缓解收缩问题 |
| **独立二分类器** | 用相同因子训练"是否极端"的分类模型（Logistic / RF 分类 / XGBoost 分类），阈值取 0.5 或按代价调整 |
| **两阶段串联** | 先用回归得到强度，再用分类器判断是否极端，最后合并为风险等级 |

> 建议：**路线 1 作为基线，路线 2 作为改进**，两者在同一测试集上比较
> Recall、F1、HSS，用数据回答"二阶段处理到底有没有用"——
> 这正是 `plans.ipynb` 所说"这一点反而建议你们保留，因为它很可能成为项目特色"。

### 2.5 预警等级设计（应用原型）

| 等级 | 判据（示例） | 含义 |
| --- | --- | --- |
| 蓝色（关注） | `Ŷ` 位于 75%—90% 分位 | 偏热，需留意 |
| 黄色（警告） | `Ŷ` 位于 90%—95% 分位 | 接近极端 |
| 红色（严重） | `Ŷ > 95%` 分位 | 极端高温风险 |

分级阈值同样**只在训练期确定**，并允许在验证集上微调。

## 三、评价流程与纪律

```mermaid
flowchart LR
    A[冻结模型] --> B[一次性预测 2021-2025]
    B --> C[连续指标: MAE/RMSE/R/R² + 置信区间]
    C --> D[阈值化: 90% / 95%]
    D --> E[分类指标: P/R/F1/AUC/HSS]
    E --> F[与气候态、持续性基线对比]
    F --> G[分提前期汇总报告]
```

| 纪律 | 说明 |
| --- | --- |
| 阈值只用训练期 | 与模型参数同等对待 |
| 报告全部提前期 | 1—4 周的技巧衰减曲线本身就是重要结论 |
| 报告全部基线 | 至少给出气候态与持续性两条参照 |
| 给出不确定区间 | 用分块 bootstrap |
| 保留负结果 | 若某指标不理想，如实报告并分析原因 |

## 四、常见陷阱

| 陷阱 | 后果 | 防范 |
| --- | --- | --- |
| 用 Accuracy 评价极端事件 | 模型全报"非极端"也有 90%+ 准确率 | 用 Recall / F1 / HSS / PR-AUC |
| 阈值取自全期数据 | 测试期信息泄漏 | 只用训练期 |
| 在测试集上优化判定阈值 | 测试集失去独立性 | 在验证集上调 |
| 只看 R 不看 RMSE | 忽略了系统偏差与振幅压缩 | 指标联合解读 + 报告标准差比 |
| 忽略自相关 | 置信区间过窄、显著性虚高 | 分块 bootstrap |
| 不与基线对比 | 无法说明机器学习的价值 | 必报技巧评分 |
| 只报最好的提前期 | 选择性报告 | 1—4 周全部报 |
